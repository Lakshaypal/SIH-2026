2. Uniform Regridding & Preprocessing Pipeline

Bilinearly interpolates multi-source satellite grids to uniform 101 × 241 mesh and normalizes into tensor [7, 101, 241]:

import numpy as np

TARGET_LATS, TARGET_LONS = np.arange(5.0, 30.25, 0.25), np.arange(45.0, 105.25, 0.25)
NORM = {'sst':(28.45, 2.12), 'sss':(34.78, 1.65), 'sla':(0.025, 0.118),
        'cur_u':(0.048, 0.342), 'cur_v':(0.021, 0.308), 'wind_u':(1.78, 4.45), 'wind_v':(2.14, 4.18)}

def build_input_tensor(ds_dict):
    channels = []
    for var in ['sst', 'sss', 'sla', 'cur_u', 'cur_v', 'wind_u', 'wind_v']:
        grid = ds_dict[var].interp(latitude=TARGET_LATS, longitude=TARGET_LONS, method='bilinear')
        arr = np.nan_to_num(grid.values, nan=0.0)
        channels.append((arr - NORM[var][0]) / NORM[var][1])
    return np.stack(channels, axis=0).astype(np.float32) # Returns: [7, 101, 241]

1. Network Topology (ConvNeXt + Self-Attention Bottleneck)

Encoder: Multi-Scale ConvNeXt-Tiny

Consumes [B, 7, 101, 241]. 4 stages of depthwise 7×7 convolutions extracting eddy-resolving mesoscale spatial features while retaining coastal boundary gradients.

Bottleneck: 4-Head Spatial Attention

Discovers non-local teleconnections between Arabian Sea monsoon upwelling, equatorial Kelvin waves, and Bay of Bengal thermocline deepening.

Decoder: Progressive Upsampling Head

Transposed convolutions expand feature maps back to 101 × 241, emitting continuous temperature predictions across all 15 discrete standard ocean depths.

Uncertainty Head: Monte Carlo Dropout

Dropout (p = 0.20) kept active at inference. 8 forward passes compute the epistemic standard deviation ±σ(x, y, z) for every grid cell.

2. The Compound Physics Loss Formulation

L_total = L_MSE + λ_mono · L_monotonicity + λ_therm · L_thermocline + λ_surf · L_surface
  • Empirical Argo Matchup (L_MSE): Mean squared error against held-out in-situ ARGO float profiles.
  • Halocline-Aware Monotonicity (L_mono): Penalizes dT/dz > 0 unless SSS < 32.5 PSU (Bay of Bengal barrier layer).
  • Thermocline Gradient (L_therm): Penalizes discrepancies in d²T/dz² to keep the 50–150m thermocline transition sharp.
  • Surface Boundary Consistency (L_surf): Constrains predicted 0m temperature to match satellite SST observations.

3. PyTorch Training Module with Zero-Out Mask Augmentation

import torch, torch.nn as nn, torch.nn.functional as F

class PhysicsGuidedOceanLoss(nn.Module):
    def __init__(self, l_mono=0.20, l_surf=0.30):
        super().__init__()
        self.l_mono, self.l_surf = l_mono, l_surf

    def forward(self, pred_t, true_t, sst_sat, sss_sat):
        loss_mse = F.mse_loss(pred_t, true_t)
        # Monotonicity: penalize where T(z_{k+1}) > T(z_k), allow inversion only if SSS < 32.5
        diff = pred_t[:, 1:, :, :] - pred_t[:, :-1, :, :]
        fresh_lens = (sss_sat < 32.5).unsqueeze(1)
        loss_mono = torch.mean(F.relu(diff - torch.where(fresh_lens, 0.35, 0.0)) ** 2)
        loss_surf = F.l1_loss(pred_t[:, 0, :, :], sst_sat)
        return loss_mse + self.l_mono * loss_mono + self.l_surf * loss_surf

# Zero-Out Cloud Mask: randomly zeros SST channel (p=0.25) forcing SLA/Wind inversion
def apply_zero_out_mask(x, p=0.25):
    if torch.rand(1).item() < p: x[:, 0, :, :] = 0.0
    return x

1. Hydrographic Stratification Indices

Mixed Layer Depth (MLD)

Depth at which temperature drops by 0.5°C from surface SST:

MLD = z | T(z) = SST - 0.5°C

D20 & D26 Isotherm Depths

D20: Thermocline center (shoals to ~60m in Somalia, deepens to ~120m in BoB).
D26: Base of cyclone heat reservoir integration.

2. Barrier Layer Thickness (BLT) — Vital for Bay of Bengal

Massive runoff from Ganga-Brahmaputra creates a buoyant low-salinity surface layer. The halocline forms shallower than the thermocline, creating a Barrier Layer that insulates subsurface heat and triggers explosive cyclone intensification:

BLT = ILD_T - MLD_S   (where ILD_T is Isothermal Depth and MLD_S is Salinity Mixed Depth; typically 15–45m)

3. Tropical Cyclone Heat Potential (TCHP)

Numerical integration of upper-ocean thermal energy exceeding the 26.0°C threshold:

Q = ρ · Cp · ∫₀ᴰ²⁶ [ T(z) - 26.0 ] dz    (ρ = 1024 kg/m³, Cp = 3.99 kJ/kg·°C; Units: kJ/cm²)
TCHP Value Cyclone Threat Category Operational Oceanographic Impact & Coastal Warning
< 25 kJ/cm² Low Threat (Decoupling) Negative storm feedback; strong cold upwelling rapidly weakens cyclone.
25 – 50 kJ/cm² Moderate Cyclogenesis Sufficient heat to sustain standard tropical storms and depressions.
50 – 80 kJ/cm² High Intensification Capable of fueling Category 3+ Very Severe Cyclonic Storms (VSCS).
> 80 kJ/cm² Extreme Rapid Intensification Triggers explosive cyclone growth (e.g. Super Cyclones Amphan, Fani). Immediate red alert.

4. Underwater Sound Speed & Naval ASW Acoustic Shadow Zones

Speed of sound in seawater calculated via the Mackenzie (1981) Nine-Term Equation:

C(T, S, z) = 1448.96 + 4.591·T - 0.05304·T² + 2.374×10⁻⁴·T³ + 1.340·(S - 35) + 0.0163·z

Sonic Layer Depth (SLD)

The depth of maximum sound speed in the upper water column (typically 35–65m). Creates an upper acoustic surface duct that traps high-frequency hull sonar emissions.

Acoustic Shadow Zone (Submarine Stealth Window)

Beneath the SLD, negative temperature gradients bend acoustic rays sharply downward, creating a blind shadow zone (60–180m) where submarines evade surface hull-mounted sonar.

5. Potential Fishing Zone (PFZ) Thermal Discontinuity Guidance

Pelagic fish schools (tuna, mackerel, sardines) aggregate at the thermal thermocline boundary where trapped nutrient-rich phytoplankton concentrates. The platform computes the Optimal Trawl Net Depth at argmax |dT/dz|, reducing trawler diesel search waste by ~30%.
