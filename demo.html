NEURAL ARCHITECTURE

From surface patches to continuous depth profiles

Halocline is a two-stage neural field: a convolutional encoder compresses the surrounding ocean state, and a Fourier-featured depth decoder renders any queried depth as a smooth, physically consistent temperature curve with calibrated uncertainty.

INPUT
[B, 7, 32, 32]

Surface Patch

7 channels × 32×32 grid (~8° × 8°)

→
CONDITIONING
[B, 8]

FiLM Vector

lat/lon Fourier + day-of-year sin/cos

→
ENCODER
[B, 192]

SurfaceEncoder

ResBlocks + FiLM + Global/Centre Pooling

→
DECODER
[B, L, 2]

DepthField

Fourier features + FiLM trunk → Tμ, Tσ

→
OUTPUT
T(z), σ(z)

Continuous Profile

Temperature + calibrated uncertainty at any depth

🎯

Centre + Context Pooling

Global average pooling is translation-invariant — an eddy at the edge contributes equally to one directly over the target. We concatenate centre features with pooled features so the model knows both "what is directly below" and "what is the surrounding field".

🌊

Continuous Depth (Not 15 Heads)

The decoder takes depth as a continuous input via Fourier features on log(1 + z/20). This produces smooth, differentiable curves — not 15 independent outputs that can disagree. Query any depth, including ones never seen in training.

📐

CRPS Loss (Not MSE)

The Continuous Ranked Probability Score is a strictly proper scoring rule: it rewards accuracy AND honesty. Claiming ±0.1°C and being wrong by 2°C is punished far harder than admitting ±2°C. Closed-form for Gaussians — no sampling needed.

🔄

No Forced Monotonicity

Standard models force T to decrease with depth. But winter Bay of Bengal inversions are real — fresh river runoff caps warmer subsurface water. Our smoothness penalty prevents jagged profiles without preventing valid inversions.

PHYSICS-GUIDED LOSS

Composite Training Objective

ℒ = CRPS(𝒩(μ, σ), y) + λ · ‖∂²T/∂z²‖²
CRPS Calibrated probabilistic fit — model can't fake confidence
CURVATURE Second derivative penalty — separates noise from real structure
MASK Sea floor masking — depths below bathymetry never contribute gradients
